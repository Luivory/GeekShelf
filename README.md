# GeekShelf 📚🎮

GeekShelf is an Android application for managing a personal physical
collection of books and video games.

The project is being developed as a personal portfolio project while
studying Development of Multiplatform Applications (DAM).

## Technologies

- Kotlin
- Jetpack Compose
- Room
- SQLite
- Git / GitHub

## Planned features

- 📚 Book catalogue
- 🎮 Video game catalogue
- 🔎 Search and filtering
- ⭐ Personal ratings
- 📦 Collection management
- 🗃️ Local database
